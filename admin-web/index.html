需要配置云函数地址

请先部署 adminApi 云函数并配置 HTTP 触发器，
然后在本文件顶部的 CONFIG 中填入云函数地址。

配置步骤：

  1. 在微信开发者工具中，右键 cloudfunctions/adminApi → 上传并部署
  2. 打开云开发控制台 → 云函数 → adminApi → 编辑环境变量，添加 ADMIN_SECRET_KEY = 你的暗号
  3. 在云函数详情页 → 触发器 → 开启 HTTP 触发器，获取访问地址
  4. 编辑本文件 admin-web/index.html 顶部 CONFIG 的 cloudFuncUrl
  5. 刷新本页面，用暗号登录
